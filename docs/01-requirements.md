# 01 需求理解与拆解

## 题目背景

小影内容团队需要批量生产短视频脚本。一条合格的脚本必须同时满足三件事：

1. **事实可靠**：脚本里出现的产品参数/卖点，必须有据可查，不能编造效果数据（如"效率提升 80%"）；
2. **时长可控**：成片要卡在用户指定的目标时长内，超时长需要压缩或明确告知无法满足；
3. **可编辑**：输出是结构化的分镜脚本（画面/旁白/字幕/素材来源），运营能直接改。

当前由人工边查资料边写稿，费时且容易写出无依据的卖点。本题要求构建一个 AI Agent，自动完成"查素材 → 写脚本 → 卡时长 → 过规则 → 交付（或说明问题）"。

## 核心目标

给定一次生成任务（主题 + 平台 + 目标时长等），Agent 自主完成：

```
校验输入 → 检索素材 → 撰写脚本 → 估算时长 → 规则检查 → （压缩/修正）→ 输出脚本 或 明确失败
```

整个过程遵循 **ReAct 循环**：模型选择动作 → 执行工具 → 观察结果 → 据此调整下一步或结束。

## 需求拆解

### 功能需求

| 编号 | 需求 | 说明 |
| --- | --- | --- |
| F1 | 输入校验 | 缺少主题/平台/目标时长等关键字段时，请求用户补充，不凭空假设 |
| F2 | 素材检索 | 按主题检索产品素材；无结果时可改写查询重试，仍无则请求补充素材 |
| F3 | 脚本撰写 | 生成分镜脚本（画面/旁白/字幕/素材 ID），每个产品事实标注来源素材 |
| F4 | 时长估算 | 按语速将旁白折算为秒数，判断是否满足目标时长硬约束 |
| F5 | 规则检查 | 校验时长上限、事实是否都有素材支撑、是否含绝对化用语/无依据效果承诺 |
| F6 | 调整与失败 | 超时长/违规时压缩或修正；无法满足时**明确失败**并说明原因 |
| F7 | 结果交付 | 最终结果可追溯到工具观察，输出结构化、可编辑的脚本 |

### 硬性边界（不可违反）

| 编号 | 边界 |
| --- | --- |
| B1 | **不得编造**素材中没有的产品事实或效果数据 |
| B2 | 目标时长是**硬约束**，不得静默超出；无法满足须明确失败 |
| B3 | 关键信息缺失时**请求补充**，不擅自假设平台/时长 |
| B4 | 无可用素材时**不生成**无事实依据的脚本 |
| B5 | 设置执行步数/工具调用次数上限，超限返回明确的**未完成**状态 |
| B6 | 最终结论必须由工具观察结果推导，模型不得虚报 |

### 验收点（来自题目）

| # | 验收点 | 对应示例 |
| --- | --- | --- |
| 1 | 正常生成（含超时长修正） | `01_normal`（30s，初稿超长 → 压缩到达标） |
| 2 | 关键信息缺失 | `02_missing_info`（缺 target_duration_sec） |
| 3 | 无可用素材 | `03_no_material`（主题无对应素材） |
| 4 | 工具失败后恢复 | `04_tool_failure`（注入 estimate_duration 失败） |
| 5 | 超时长无法满足 → 明确失败 | `05_over_length_fail`（目标 5s） |
| 6 | 步数/调用上限 → 明确未完成 | 单元测试 stub 模型 |

## 输入 / 输出约定

**输入（任务）**：

```json
{
  "case_id": "01_normal",
  "topic": "智能台灯",
  "audience": "大学生",
  "platform": "抖音",
  "target_duration_sec": 30,
  "style": "轻松种草",
  "notes": "可选：额外要求",
  "inject_failures": { "estimate_duration": 1 }
}
```

> `inject_failures` 为可选字段，仅用于评测时注入工具故障，验证失败恢复路径。

**输出（final_result）**：

```json
{
  "case_id": "01_normal",
  "status": "completed | failed | needs_input | max_steps",
  "reason": "结束说明（可追溯到工具观察）",
  "missing": ["target_duration_sec"],
  "title": "智能台灯｜抖音30秒短视频脚本",
  "target_duration_sec": 30,
  "estimated_total_sec": 25.1,
  "segments": [
    { "shot": 1, "visual": "画面描述", "narration": "旁白", "subtitle": "字幕", "material_ids": ["P01"] }
  ],
  "material_ids": ["P01", "P02", "P03"],
  "risks": ["R1: 预计总时长 33s 超过目标 30s"],
  "run": { "llm": "mock", "steps": 7, "tool_calls": 6, "max_steps": 16, "max_tool_calls": 16, "finished_action": "finish" }
}
```

**状态语义**：

- `completed`：脚本产出且通过时长与规则检查；
- `failed`：无法满足约束（超时长/不可修复违规/工具连续失败）；
- `needs_input`：缺少关键信息或无素材，需用户补充；
- `max_steps`：达到步数/工具调用上限，任务未完成。
